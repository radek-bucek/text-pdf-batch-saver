Batch configuration

The site adapter lives here: regexes, URL templates and file-name patterns. All the machinery is generic and built into the extension. Keyboard shortcuts are set per task with hotkey = ctrl+shift+s and work while a web page is focused. Format reference: README.md in the extension folder.

The configuration is empty, so Ctrl+Shift+S just saves the shown page as a text PDF, exactly as it is (no content analysis). Set the destination folders here - a filled field becomes a subfolder, an empty one is skipped. The file name is the page title plus a timestamp.
